# Privacy Policy

**Last updated:** 2026-05-26

## Summary
Static read-only portfolio dashboard. No personal data collected, stored, or transmitted from visitors.

## Data Collection
- Zero server-side tracking. No cookies, no tracking pixels, no fingerprinting, no third-party analytics.
- Local analytics only. Visit/click analytics stored exclusively in visitor's own browser IndexedDB. Never transmitted anywhere.
- GitHub OAuth (admin only). `/admin` route uses GitHub OAuth exclusively for @AkashPriyadarshii. No visitor is ever asked to authenticate.

## Third-Party Services
| Service | Purpose | Data sent |
|---------|---------|-----------|
| GitHub Pages | Hosting | Standard server access logs (GitHub's privacy policy applies) |
| Google Fonts | Typography | Font requests (Google's privacy policy applies) |
| jsDelivr | CDN | Asset requests only |
| GitHub API | Profile data | Public data, no auth required |
| Vercel Functions | OAuth token exchange (admin only) | GitHub OAuth code, one-time per admin login |

## Clear Local Data
Browser DevTools → Application → IndexedDB → delete `analytics_db`
