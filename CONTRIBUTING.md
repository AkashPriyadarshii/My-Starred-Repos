# Contributing Guide

Contributions are welcome. Please open a discussion issue before submitting pull requests.

## Tech Stack Constraints
* **Vanilla Foundations:** Pure HTML5, CSS3, and ES6+ JavaScript. No NPM build frameworks, compilers, or styling utilities (e.g. React, Vue, Tailwind).
* **CDN Libraries:** The only approved CDNs are Lucide Icons, Marked.js, and Chart.js.
* **Architecture:** Static cache-driven design. No multi-user backend modifications.
