# Starred Repos — repo notes

GitHub-starred-repos dashboard, v0.3. Static SPA + one serverless search endpoint on Vercel.
**No Vercel CLI deploys: pushing to `main` triggers the deploy.** No GitHub releases or tags; version lives in `CHANGELOG.md`.

## Data pipeline

- `fetch_stars.py` — pulls starred repos from the unauthenticated public GitHub API. Full sync by default (`--incremental` stops at the first known repo: fewer requests, stale metadata, no prune). Writes `schema_version`, `sync_mode`, `requests_used`, and per-repo `synced_at`.
- `build_site.py` — bakes `repos_output.json` into `index.html` + `llms.txt` + `llms-full.txt` + `sitemap.xml`. Sole writer of those files; never hand-edit them. `--check` exits 1 when committed output drifts.
- `api/search.js` — serverless GET search over `repos_output.json` with CORS, pagination, and `X-Data-Age`.
- `generate_assets.py` — icons, favicon, OG image, manifest. Only when the brand changes.
- Sync: `python fetch_stars.py && python build_site.py`. No cron, no workflow, no database. The snapshot age is shown in the header; treat staleness as normal.

## Key files

| File | Role |
|------|------|
| `index.html` | **Generated by `build_site.py`** — do not hand-edit |
| `app.js` | SPA: fetch → profile → metrics → tabs → filters → grid/compact (compact is default) → matcher → pins |
| `style.css` | Warm charcoal + amber theme, OKLCH tokens, hairline rules |
| `api/search.js` | Search endpoint: GET/HEAD only, 400 on unknown enum, empty filter = no filter |
| `vercel.json` | `cleanUrls`, security headers, cache policy for `repos_output.json` and `/api/*` |
| `repos_output.json` | Generated dataset — never hand-edit |
| `tests/` | `test_contract.py` (stdlib unittest), `test_api_search.mjs` (`node:test`) |

## Conventions

- Every repo-derived string goes through `escapeHTML()` before template insertion, `repo.url` in `href` included.
- No `console.log` in production code.
- Asset cache busters are content hashes (`asset_version()`), not hand-edited counter constants.
- `localStorage` reads go through `readStore`/`readJSONStore`; a malformed value must never break the first render.
- `.omc/`, `.codegraph/`, `*-audit/` are local tooling and stay git-ignored.

## Verify

```bash
node --check app.js api/search.js

python build_site.py --check
python -m unittest discover -s tests -v
node --test tests/test_api_search.mjs
```

## Known behavior

- Vercel edge-caches `repos_output.json` (`s-maxage` + SWR), so the live dataset can trail the repo by up to ~1h after a deploy. A push redeploys; it is not a live feed.
- Diagnose staleness with `curl -sI https://my-starred-repos.vercel.app/repos_output.json` (`X-Vercel-Cache`, `Age`) or `/api/search` (`X-Data-Age`).
