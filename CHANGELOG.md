# Changelog

All notable changes to My-Starred-Repos.

## [v0.1] — 2026-08-28

Initial public version. Auto-sync pipeline is live; SEO + GEO optimization complete.

### Added
- **SEO & GEO overhaul**: `<meta name="keywords">`, Schema.org `keywords` array, topic badge cloud (10 search clusters: AI Agents, MCP, Claude Code Skills, LLM & RAG, Rust CLI, Dev Tools, System Design, Android, Web Automation, Security)
- **FAQ section** in pre-rendered HTML — citation-ready for Google AI Overviews and Perplexity
- **`llms.txt` / `llms-full.txt` Topic Taxonomy** block for AI search engine indexing
- **Chunked progressive rendering** in `app.js` (`BATCH_SIZE=60`, `IntersectionObserver`) — cuts initial DOM nodes from 7,100+ to ~450, improving INP
- **Dynamic `sitemap.xml`** generated by `build_site.py` with daily `<lastmod>`
- **Asset caching** in `vercel.json` for `style.css` and `app.js`
- **LLM endpoints** in `robots.txt`
- **Person schema entity graph** with `sameAs` links (GitHub, X, LinkedIn, Portfolio)
- **SERP snippet optimized**: title ~53 chars, meta description ~152 chars
- **Interactive topic badges** — clicking auto-filters the live grid

### Fixed
- `clean_summary()` sentence splitter no longer cuts abbreviations like `f.k.a.` or filenames like `CLAUDE.md`
- Taxonomy keyword matching switched to word-boundary for short keywords (< 4 chars) — fixes false positives like "ai" matching "gmail", "main", "container"
- JSON-LD `about.itemListElement` was double-encoded as a string — now a proper array

### Infrastructure
- `sync-stars.yml` runs `build_site.py` after every fetch; commits `index.html` + `llms.*` + `sitemap.xml`
- Vercel auto-deploys on push to `main` — no manual `vercel --prod` needed
